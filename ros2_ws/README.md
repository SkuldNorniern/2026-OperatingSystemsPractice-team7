# ros2_ws

ROS 2 colcon workspace for the project. Target: Ubuntu 24.04 with ROS 2 Jazzy.

> The workspace is currently empty. Packages go under `src/`, which is created when the first package is added.

## Layout

```
ros2_ws/
├── src/        # ROS 2 packages (source, tracked by git)
├── build/      # generated by colcon (git-ignored)
├── install/    # generated by colcon (git-ignored)
└── log/        # generated by colcon (git-ignored)
```

## Setup

```bash
sudo apt install python3-colcon-common-extensions
source /opt/ros/jazzy/setup.bash
```

## Build

```bash
cd ros2_ws
colcon build --symlink-install
source install/setup.bash
```

Build a single package:

```bash
colcon build --packages-select <package_name>
```

## Run

After sourcing `install/setup.bash`:

```bash
ros2 run <package_name> <executable_name>
ros2 launch <package_name> <launch_file>
```

## Clean rebuild

```bash
rm -rf build install log
colcon build --symlink-install
```
